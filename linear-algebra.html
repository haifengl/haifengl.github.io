Linear Algebra

SMILE’s numerical core lives in smile.tensor: Vector, DenseMatrix, SparseMatrix, BandMatrix, and SymmMatrix, plus factorizations (LU, QR, Cholesky, SVD, eigen). Heavy ops call native BLAS/LAPACK via Java FFM when available and automatically fall back to pure-Java implementations (JBlas and JLapack) otherwise. You can inspect availability with NativeLibrary.isBlasAvailable() / isLapackAvailable() or select the backend via -Dsmile.linalg.backend=auto|native|java (or the SMILE_LINALG_BACKEND environment variable).

This page walks from scalar helpers through vectors and matrices to decompositions. Java uses the tensor API directly; Scala adds a lazy expression DSL (+, *, %*%, \) on top of the same types.

Math Functions

Besides java.lang.Math, smile.math.MathEx covers combinatorics, norms, distances, correlations, and related helpers used throughout the library.

import static smile.math.MathEx.*

choose(10, 3)

Special Functions

smile.math.special provides beta, erf / erfc, gamma / lgamma, and digamma. These show up in probability, statistics, and differential equations — for example erfc(x) = 1 - erf(x) is a special case of the incomplete gamma function.

import smile.math.special.*

Matrix–vector products use mv (and tv for Aᵀx). In Scala, A * x is the same product inside the expression DSL.

import smile.tensor.*
import static smile.linalg.Transpose.NO_TRANSPOSE

var a = DenseMatrix.of(new double[][] {
    { 0.7220180,  0.07121225, 0.6881997},
    {-0.2648886, -0.89044952, 0.3700456},
    {-0.6391588,  0.44947578, 0.6240573}
})
var x = Vector.column(new double[]{1.0, 2.0, 3.0})
var y = Vector.column(new double[]{3.0, 2.0, 1.0})

a.mv(x)                                // A x
a.mv(NO_TRANSPOSE, 1.0, x, 1.5, y)    // y := A x + 1.5 y
y

Scala * on matrices is element-wise. True matrix multiplication is %*% (R-style) or Java mm / mt / tm (A B, A Bᵀ, Aᵀ B).

import smile.tensor.*

var a = DenseMatrix.of(new double[][] {
    { 0.7220180,  0.07121225, 0.6881997},
    {-0.2648886, -0.89044952, 0.3700456},
    {-0.6391588,  0.44947578, 0.6240573}
})
var b = DenseMatrix.of(new double[][] {
    {0.6881997, -0.07121225,  0.7220180},
    {0.3700456,  0.89044952, -0.2648886},
    {0.6240573, -0.44947578, -0.6391588}

transpose() materializes immediately. On a Scala MatrixExpression, prefer lazy .t so a product chain can fuse transpose into mt / tm. Scala also picks an optimal parenthesization for %*% chains (matrix-chain ordering).

import smile.tensor.*
import static smile.tensor.ScalarType.Float64

var a = DenseMatrix.randn(Float64, 300, 900)
var b = DenseMatrix.randn(Float64, 900, 150)
var c = DenseMatrix.randn(Float64, 150, 1800)
var d = DenseMatrix.randn(Float64, 1800, 30)

var r = a.mm(b).mm(c).mm(d)
r.nrow() + " x " + r.ncol()

300 x 30

Matrix Decomposition

DenseMatrix exposes lu, qr, cholesky, svd, and eigen. From those you get determinants, ranks, inverses, and linear solves. Scala also wraps common cases as lu, qr, inv, det, rank, and the solve operator \.

import smile.tensor.*

var a = DenseMatrix.of(new double[][] {
    { 0.7220180,  0.07121225, 0.6881997},
    {-0.2648886, -0.89044952, 0.3700456},
    {-0.6391588,  0.44947578, 0.6240573}
})

var inv = a.inverse()
inv.mm(a)                              // ≈ I

a.lu().solve(new double[]{1.0, 2.0, 3.0})  // solve A x = b
