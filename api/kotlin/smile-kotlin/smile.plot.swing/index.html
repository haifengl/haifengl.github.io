smile-kotlin/smile.plot.swing

Package-level declarations

Mathematical and statistical Swing plots.

Swing based data visualization provides interactive charts and graphs including scatter plots, line plots, bar charts, box plots, histograms, QQ plots, heatmaps, contour plots, 3D surface and wireframe plots, and dendrograms.
