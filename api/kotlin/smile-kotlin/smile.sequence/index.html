smile-kotlin/smile.sequence

Package-level declarations

Sequence labeling algorithms.

Sequence labeling is a type of pattern recognition task that involves the algorithmic assignment of a categorical label to each member of a sequence of observed values. Common examples include part-of-speech tagging, named-entity recognition, and gene prediction.
