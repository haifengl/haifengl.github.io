Data structures, data frames, and manipulation utilities.

A DataFrame is a two-dimensional, potentially heterogeneous tabular data structure with labeled axes (rows and columns). It supports flexible row/column indexing, slicing, functional query operations (filtering, partitioning, grouping), operator overloading for intuitive access and manipulation, and JSON serialization.
